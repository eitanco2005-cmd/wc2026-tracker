# NBA × ווינר — מערכת המלצות

מושכת את כל שווקי ה-NBA מווינר, מעריכה לכל אפשרות הסתברות אמיתית, וממליצה רק על הימורים
שבהם `הסתברות × יחס ווינר > 1` בפער מספיק. פרליים נבנים רק מרגליים כאלה.

## התקנה (פעם אחת)
```
pip install -r requirements.txt
python -m playwright install chromium
```

## שימוש יומי
```
python run.py            # המלצות להיום → דו"ח HTML נפתח אוטומטית
python run.py settle     # למחרת: מכריע את ההימורים מאתמול ומעדכן רווח/הפסד
python run.py ratings    # טבלת דירוגי הקבוצות של המודל
```
ריצה ראשונה מורידה עונה וחצי של תוצאות מ-ESPN (2-4 דקות); אחר כך הכול מהמטמון.
הזמן הכי טוב להריץ: בערב (שעון ישראל), אחרי שדוחות הפציעות מתעדכנים ולפני המשחקים.

אם ווינר חוסם את המשיכה: `python run.py --show-browser`.

## מה המערכת בודקת
| שכבה | מקור | מה נלמד |
|---|---|---|
| תוצאות | ESPN, העונה הנוכחית + קודמת | דירוג כוח לכל קבוצה (ridge, משקל דועך לפי זמן), יתרון ביתיות, השפעת בק-טו-בק |
| נקודות | ESPN | דירוג התקפה/הגנה נפרד לסך נקודות |
| פציעות | ESPN injuries + סטטיסטיקת שחקן | ערך השחקן מעל מחליף × סיכוי שייעדר |
| שוק חד | קווי DraftKings דרך ESPN | הסתברות ללא מרווח — משוקללת 70% |
| מחציות/רבעים | קווי רבעים היסטוריים | יחסי מחצית/רבע וסטיות תקן מכוילים מהנתונים |

שווקים נתמכים: הימור יתרון (משחק/מחצית/רבע), מעל/מתחת (משחק/מחצית/רבע), סך נקודות קבוצתי, מנצחת.
לא נתמכים: שלשות, סל ראשון, הראשונה ל-10/20, מחצית/סיום, כוכב הלילה.

## דרגות
- **A** – משחק מלא, מעוגן בשוק החד. סף EV 2%.
- **B** – מחצית / קבוצתי. סף 4%.
- **C** – רבע ראשון. סף 6%.
כשהמודל רחוק מאוד מהשוק (7+ נק' בהפרש / 12+ בסך) המשחק נחסם — כמעט תמיד זה מידע שהמודל לא יודע.

## הגדרות
הכול ב-`nbaw/config.py`: בנקרול, חלק קלי, ספי EV, מספר רגליים בפרליי, משקל השוק.

## קבצים
- `reports/` — דו"ח לכל ריצה
- `data/picks.csv` — יומן ההמלצות והתוצאות (פתיח באקסל)
- `data/winner_nba_*.json` — צילום ליין ווינר לכל ריצה
- `cache/` — היסטוריית ESPN

## המציאות
ווינר מתמחר שווקי NBA דו-כיווניים ב-1.75/1.75 עד 1.80/1.80 — מרווח של 11%-14% לשוק
(בתי הימורים בארה"ב: ~4.5%). צריך לפגוע ב-55.6%-57.1% רק כדי לא להפסיד. בפרליי של 3 רגליים
המרווח המצטבר מגיע ל-~30%. לכן ברוב הימים המערכת תגיד "אין הימור", וההזדמנויות האמיתיות
יבואו בעיקר מקווי מחצית/רבע של ווינר שלא מתואמים לקו המשחק, או מקווים של ווינר שלא זזו אחרי חדשות.
`settle` עוקב אחרי רווח בפועל מול רווח צפוי — אחרי 100+ הימורים תדע אם יש כאן יתרון אמיתי.
